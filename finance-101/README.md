# 金融市场图解课

一部约 11 分钟的中文动画讲解视频，面向零基础读者，讲清楚这些基本概念：

| 章节 | 内容 |
| --- | --- |
| 01 金融市场是什么 | 资金如何从投资者流向企业和政府，回报如何流回 |
| 02 一级市场与二级市场 | IPO 与发行市场、流通市场，新房 / 二手房的比喻 |
| 03 广义的一级市场 | 天使轮、VC、PE、Pre-IPO 到上市退出 |
| 04 股票 | 所有权、分红与价差、市值 |
| 05 K 线 | 开盘 / 收盘 / 最高 / 最低，阳线与阴线，A 股红涨绿跌 |
| 06 市盈率 | PE = 股价 ÷ 每股收益 |
| 07 债券 | 面值、票面利率、期限，利率与债券价格的跷跷板 |
| 08 基金 | 一篮子资产、分散风险、指数基金与 ETF |
| 09 衍生品 | 标的资产与衍生品 |
| 10 期货 | 农民与面包厂的套期保值 |
| 11 保证金与杠杆 | 10 倍杠杆下的盈亏、每日结算、做多做空 |
| 12 期权 | 权利金与行权价（买房定金的比喻） |
| 13 看涨 / 看跌期权 | 买方到期盈亏图 |
| 14 期权买方与卖方 | 权利与义务、收益与风险 |
| 15 常见术语 | 牛市熊市、做多做空、涨跌停、T+1 |
| 16 总结 | 五种工具对比表与风险梯度 |

## 文件

- `finance-101.mp4`：1920×1080 视频，画面配中文字幕（无配音）。
- `index.html`：可交互版本。用浏览器直接打开，支持播放 / 暂停、拖动进度、章节跳转、倍速、全屏，并附完整文字稿。点击“朗读”会用浏览器自带的中文语音配音。

快捷键：空格 播放 / 暂停，← → 快退 / 快进 5 秒。

## 重新导出视频

`index.html?record` 是录制模式：隐藏控件、画面铺满窗口、字体加载完后自动从头播放，播完时设置 `window.__done = true`。用无头浏览器以 1920×1080 打开这个地址并录屏即可得到视频。
